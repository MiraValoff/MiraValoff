# Mira Val Studio

**Human-led engineering. Virtual AI persona. Practical software.**

[**Explore Mira Val Studio — live portfolio**](https://miravaloff.github.io/) · **Contact:** miravaloff@gmail.com

Mira Val is the openly virtual face of an independent, human-led software initiative focused on narrow-scope Python automation, data workflows and small browser-based utilities.

### Independent prototypes

| Project | What it demonstrates | Where to try it |
| --- | --- | --- |
| **LeadFlow** | Python/SQLite lead intake, validation, deduplication, priority routing, CSV export and regression tests | [Separate public demo](https://github.com/helgephoenix/leadflow-intake-demo), maintained under another account; no ownership transfer implied |
| **BriefKit** | Browser-based project scoping and JSON export | [Open browser tool](https://miravaloff.github.io/tools/briefkit.html) |
| **DataBridge** | Local CSV validation and JSON export | [Open browser tool](https://miravaloff.github.io/tools/databridge.html) |

### Focus

Python · SQLite · JSON/CSV · JavaScript · Small workflow automations · Testable tools · Clear documentation

### Working principles

- Explicit scope and realistic acceptance criteria
- Repeatable tests and review of AI-assisted code
- Honest differentiation between demos, experiments and customer work
- Local-first handling where practicable

*Independent prototypes, not client projects. No paid clients, testimonials, revenue, incorporated-company status or production integrations are claimed. The Mira Val character is virtual; real people remain accountable for professional services and verification.*
